# Python-expense-tracker
A Python expense tracker for managing and tracking daily expenses# 💰 Python Expense Tracker

A simple command-line Expense Tracker built using Python. It allows users to record, view, search, and manage their daily expenses.

## ✨ Features

- ➕ Add expenses
- 📋 View all expenses
- 🧮 Calculate total spending
- 🔍 Search expenses by category
- 🗑️ Delete expenses
- ⚠️ Handles invalid input

## 🛠️ Technologies Used

- Python
- Lists
- Dictionaries
- Functions
- Loops

## ▶️ How to Run

Make sure Python is installed, then run:

```bash
python expense_tracker.py
```

Follow the menu displayed in the terminal.
